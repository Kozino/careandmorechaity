# Care & More — public website
Upload the extracted site folder (containing index.html) to Netlify Drop. No build step or dependencies. For a Git deployment, set the publish directory to the folder containing index.html. Enable Netlify form detection and redeploy; submit a test on the live site and configure email notifications in Netlify Forms. Local previews do not process form submissions. Giving enquiries do not collect payment. Illustrative photographs are from Unsplash; replace with approved foundation event images before presenting them as event documentation. Edit the HTML pages and style.css directly. No admin, database or PHP is included.
